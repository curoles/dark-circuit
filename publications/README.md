# Publications

Notes on the design of dark-circuit's blocks and cores: what was tried, what it cost, how it
was measured. Each links to the code and to the knowledge-base records (`kb/`) behind it.

| Date | Title | In short |
|---|---|---|
| 2026-11 | [Union-find as a hardware block: a payload it never reads, a mutant that survives](2026-11-union-find.md) | DisjointSet with a user-typed payload and a user-supplied merge (XOR for an odd count, not OR), union by rank and path halving two levels a clock; the mutant that survives on purpose; the gate-level version as a design review that made both versions faster (8.5 to 5.9 ns, gate-level 5.4 ns). |
| 2026-11 | [Squeezing out the zeros: stream compaction in log2(N) mux stages](2026-11-stream-compaction.md) | The present elements of a mostly-zero row moved to its front: gaps as a prefix count, every element sliding by its own gap stage by stage, no two ever colliding; 13 627 um2 and 4.2 ns against 32 265 um2 and 12.0 ns for the obvious loop. |
| 2026-11 | [What a QEC decoder actually sees: detection events for hardware designers](2026-11-qec-detection-events.md) | The front end of a surface-code decoder as library blocks: parity questions instead of reading qubits, a layout tested by what makes it a code, detection events and their two ends, and a parity-check block that costs 255 um2 tied to its matrix against 4 139 um2 programmable. |
| 2026-11 | [3.6 times faster with one instruction: an int8 layer on my RISC-V core](2026-11-int8-kernel.md) | A TFLite Micro fully connected layer in plain C and with P's PM4ADDA.B, outputs compared bit for bit: 9 220 cycles against 2 560, where the cycles go (multiplier bubbles, loads, a requantization grown from a tenth to 40 %), the register-pair trap, and why the P line in Mig3 stopped here. |
| 2026-11 | [Four pieces of one array: a packed multiplier for int8 dot products](2026-11-packed-multiplier.md) | One 16 x 16 array per lane whose 8 x 8 quadrants serve byte products, 16 x 16 products and dot products: pieces with their own signs were slower than a plain multiplier, Baugh-Wooley made it faster and smaller, and switching parts off found the dot products' costs; rows are cheap, adders are not. |
| 2026-11 | [Turning on P in clang 23: what the compiler does with RISC-V's packed SIMD](2026-11-p-in-clang-23.md) | clang 23's experimental P: the flag and its version, intrinsics without multiplies, no vectorization, yet P in ordinary C (packed constants, 64-bit math on register pairs, MACC.H00); why a core with part of P compiles P only where it is true, and checks the binary. |
| 2026-11 | [One adder, many instructions: packed SIMD in my RISC-V core](2026-11-one-adder-many-instructions.md) | 32 instructions of RISC-V's draft P in one EX cycle: a lane-cut adder shared by wrapping, saturating and min/max instructions, flags per byte, one shifter for all lanes; the rule that saved the timing twice (do not wait for the sum), and the run that showed the margin used up. |
| 2026-11 | [Floating point on the integer registers: Zfinx in my RISC-V core](2026-11-fp-on-integer-registers.md) | All of RISC-V's single-precision FP on the x registers: hybrid blocks checked by TestFloat, a 16 ns FMA pipelined by hand to 5.1 ns, every result through a register, rs3 through a read port borrowed in EX; 23 % more area, the clock unchanged. |
| 2026-11 | [Half the answers wrong: a textbook floating-point multiplier against IEEE 754](2026-11-toy-vs-real-multiplier.md) | The multiplier every textbook draws, run on TestFloat's level-1 cases: 47.9 % wrong (exact only rounding toward zero, for normal numbers); what a fused multiply-add needs instead, the bugs only the reference found, and the cost: twice the area, the same clock once staged by hand. |
| 2026-11 | [The DMA wrote it, the cache kept the old copy: cbo.inval on my RISC-V core](2026-11-dma-and-cbo.md) | A stale line caught in a trace, then dropped by Zicbom: a CBO is a store of no bytes with its operation, carried down to where a lower cache will act on it; the testbench allows the old value or the new one until the CBO retires. |
| 2026-11 | [Atomics next to the memory: my core sends AMOADD as a load](2026-11-atomics-next-to-memory.md) | The read-modify-write of RISC-V's AMOs done in front of the memory, where every agent's accesses meet: the core sends a load with AXI5's operation code, the caches step aside, and the core gets simpler (0.4 % area, the clock unchanged). |
| 2026-11 | [The register port: a device is its registers, one clock per access](2026-11-register-port.md) | A twenty-line block turns a bus handshake into one-clock accesses: a read's side effect happens once by construction, the answer is a flop, ready comes from flops; the PLIC, the timer and the UART are wiring behind it. |
| 2026-11 | [Replay instead of refuse: getting 0.5 ns back](2026-11-replay-instead-of-refuse.md) | A cache that takes a request in its refill clock: the obvious guard cost 8 % of the clock, replaying the conflicting request costs nothing and keeps the 18-20 % fewer cycles. |
| 2026-11 | [EXPECT_REG: register expectations that live in the test binary of self-checking assembly tests](2026-11-expect-reg.md) | Expected register values as a table after the halting instruction, checked by the testbench against the retired results: a test that does not ask the CPU to grade its own exam. |
